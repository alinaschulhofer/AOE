Install

  1. Gmail: Settings (gear) → See all settings → General → Signature → Create new. Paste, then Save Changes at the bottom.
  2. Outlook (web or new Outlook): Settings → Accounts → Signatures → New signature. Paste, then Save.
  3. Outlook (classic Windows): File → Options → Mail → Signatures → New. Paste, then OK.
  4. Apple Mail (Mac): Mail → Settings → Signatures → +. Untick “Always match my default message font”, then paste into the right-hand box. Apple Mail often hides logos loaded from the web, so replace it with the file: click the empty logo spot and delete it, then drag aoe-signature-logo.png from Finder into the same spot. Close Settings to save.
  5. iPhone Mail: Settings → Apps → Mail → Signature. Paste. iOS may simplify the layout slightly.

If the logo shows as a broken image, check that https://www.architectureofexcellence.com/assets/logo-lockup.png opens in your browser.
